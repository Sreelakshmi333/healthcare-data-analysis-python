# Healthcare Data Analysis using Python

Analysis of about 55,000 hospital records using Python (Pandas, NumPy, Matplotlib, Seaborn) to find patterns in billing, hospital stay and admissions.

## Dataset
Healthcare Dataset from Kaggle (synthetic data).
Link: https://www.kaggle.com/datasets/prasad22/healthcare-dataset

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn

## What I Did
- Understood and checked the data
- Cleaned the data (duplicates, names, date columns)
- Made new columns: Stay Days, Year, Month, Age Group, Bill Level
- Used groupby and pivot table to find answers
- Made charts to show the results

## Key Insights
1. Obesity has the highest average bill, but all conditions are very close.
2. Cigna has the highest total billing, then Medicare and Blue Cross.
3. Patients stay about 15.5 days on average.
4. August has the most admissions and February has the fewest.
5. Elective admissions have the highest average bill, but all three types are almost equal.
6. The 65+ age group has the most patients.

## Note
The data is synthetic, so most values look very even.
